# 支付完成页设计

## 背景与目标

Portal 现有支付流程在订单状态推进后仍停留在付款界面，用户无法得到统一、明确的“额度已到账”反馈。参考 `F:\WorkSpace\study\AIProject\New-api\usdt` 的完成页体验，本设计在额度实际到账后展示独立完成页，并在五秒后引导用户进入控制台概览。

## 范围

- 新增受 Portal 控制台路由保护的 `/console/payment-complete` 页面。
- 仅当服务端订单状态为 `PAID` 时展示支付完成内容。
- 支持 TRC20-USDT 与 PayPal 两种渠道进入同一完成页。
- 显示到账成功、订单金额、到账额度、订单号和五秒倒计时。
- 提供“立即创建 API Key”入口跳转 `/console/tokens`；无人操作时跳转 `/console/dashboard`。
- 完成页刷新时按订单号重新读取服务端订单，拒绝非 `PAID` 状态伪造成功内容。

不包含链上核验、PayPal 捕获、订单入账状态机和订单管理恢复操作的改动。

## 页面与路由

完成页通过查询参数接收订单号：`/console/payment-complete?orderNo=...`。页面载入后调用既有订单详情 API，客户端不从 URL、缓存或前一页状态读取金额、额度、用户或支付结果。

1. 订单为 `PAID`：展示成功图标、订单号、支付金额、已到账额度、“5 秒后自动跳转到概览页”文案和“立即创建 API Key”按钮。
2. 订单不存在、不属于当前会话用户、订单号缺失或状态不是 `PAID`：不展示成功内容；使用明确的错误或处理中状态，并提供返回订单管理或充值页的安全入口。
3. 订单读取中：展示加载状态，倒计时尚未开始。

## 倒计时与跳转

服务端确认订单为 `PAID` 后，前端从 5 开始每秒递减。减至 0 时使用 `window.location.assign('/console/dashboard')` 进行顶层跳转。

点击“立即创建 API Key”时，先清除计时器，再跳转 `/console/tokens`。组件卸载、订单读取失败或状态不为 `PAID` 时也必须清除或不创建计时器，避免背景跳转。倒计时期间用户可正常浏览已到账信息。

## 支付流程衔接

现有支付页只在收到服务端订单 `PAID` 状态时跳转完成页：

- TRC20：轮询订单详情或提交 TxID 后刷新得到 `PAID` 时跳转。
- PayPal：捕获成功后的订单详情为 `PAID` 时跳转；若仍是 `CONFIRMED` 或 `CREDITING`，保持当前页面和已有处理中反馈，继续等待最终状态。

跳转 URL 仅携带 `encodeURIComponent(orderNo)`。完成页仍通过当前会话调用订单 API 校验归属，不能凭借 URL 参数绕过授权。

## 前端结构

- 新增 `PaymentCompletePage`，专门负责：读取订单、控制倒计时、渲染成功/加载/安全失败状态、处理两种跳转。
- 在 `App.tsx` 的控制台路由集合中加入完成页路径，并在对应的控制台路由模块中渲染该页面；完成页不需要加入侧边栏导航。
- 支付相关组件保留各自的渠道动作，仅把“订单状态变成 `PAID`”交给共享导航函数，避免 TRC20 与 PayPal 产生不同成功标准。
- 继续复用 `getPaymentOrder`、`formatUsd`、`formatQuota`、`RemoteState` 和现有控制台布局/样式体系。

## 错误处理与安全

- `PAID` 是唯一成功状态；禁止把 `CONFIRMED`、`CREDITING`、`CREDIT_FAILED`、`CREDIT_UNKNOWN`、`EXPIRED`、`CANCELLED` 作为完成成功。
- 后端订单详情仍根据当前 `PORTAL_SESSION` 检查归属；前端不能传入或信任用户 ID、额度、金额、支付状态。
- API 读取失败不启动倒计时，并显示重试入口。
- URL 缺少或非法订单号不发起不安全推断，显示安全失败页。

## 测试策略

- 完成页：`PAID` 订单显示成功信息和初始 5 秒；假时钟走满 5 秒跳转 dashboard；点击 API Key 取消倒计时并跳 tokens；非 `PAID` 或读取失败不显示成功也不跳转。
- 路由：直接访问 `/console/payment-complete?orderNo=...` 渲染完成页。
- 支付衔接：TRC20 与 PayPal 仅在订单状态 `PAID` 时调用完成页导航；处理中状态不得提前跳转。
- 生产构建与现有支付、订单测试一并回归。

## 验收标准

用户在任意支持支付方式的订单额度实际到账后都会看到独立支付完成页。页面五秒后自动进入控制台概览，用户也可立即创建 API Key。刷新或伪造完成页 URL 不会展示不属于当前用户或未到账订单的成功信息。
