# Portal 支付中文日志设计

## 目标

为 Portal 后端的完整支付闭环提供可追踪的中文业务日志，方便按订单号排查创建订单、第三方支付确认、链上核验和 NewAPI 额度入账。

## 范围

覆盖订单创建与查询、PayPal 下单/捕获/Webhook 验签、TRC20 地址分配/扫描/TxID 核验/订单过期，以及确认后的 NewAPI 额度入账与恢复任务。

## 日志约定

- 成功的关键状态变化使用 `INFO`；可恢复或被安全拒绝的异常分支使用 `WARN`；外部服务调用出现不可判定异常使用 `ERROR` 并附带异常栈。
- 统一记录订单号、支付方式、用户 ID、金额（分或最小单位）、计划入账额度、订单状态、外部订单号/捕获号/交易哈希等排障字段。
- 不记录会话 Cookie、PayPal OAuth Token、Client Secret、Webhook 签名与证书地址、NewAPI Access Token、TronGrid API Key 或原始回调报文。
- 高频轮询只在状态变化、查询失败、匹配到交易、确认数不足、重试安排或到期时记录，避免每次空扫描产生日志噪音。

## 验证

针对支付确认、入账成功/失败/未知、PayPal 回调验签失败与重复事件、TRC20 TxID 未索引/确认/不匹配等现有单元测试执行回归；新增日志断言只验证安全的结构化字段和中文事件文本，不断言或捕获敏感值。
